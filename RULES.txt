LEVELHEADED PROJECT - GLOBAL RULES
These rules apply to the entire project and should be reviewed on every major change or ZIP upload.

Core Philosophy
---------------
- The game world remains in METERS internally (Minecraft native scale).
- Survey output (CSV + HUD) can be converted to feet or chains.
- Prioritize stability and real surveying usability over visual flair.
- Keep the mod lightweight and maintainable.
- Target compatibility between Java and future Bedrock versions.  Avoid Java specific functions like mixins where possible.
