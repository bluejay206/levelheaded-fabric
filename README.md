# SurveyorSays

A surveying mod for Minecraft 1.21.1 Fabric.

## Features
- Surveyor's Rod & Scope with real-time HUD (bearing, azimuth, zenith angle, distances, ΔN/ΔE, cut/fill)
- Transit Station block (right-click to set occupy point)
- V key to save shots → PNEZD CSV export
- H key to toggle HUD
- Multiplayer support

## Installation
1. Install Fabric Loader 0.18.6+ for Minecraft 1.21.1
2. Download the latest `.jar` from Releases
3. Put it in your `mods` folder

## Usage
- Place a Transit Station and right-click it to set the occupy point.
- Hold Rod or Scope → HUD appears.
- Right-click to lock a shot → press **V** to save.
- Press **H** to toggle HUD.
